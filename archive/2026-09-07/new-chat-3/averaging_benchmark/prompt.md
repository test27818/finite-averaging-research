# 任务

给定 $n$ 个整数（多重集），每次操作取两个数 $x,y$，把它们**都**换成 $\frac{x+y}{2}$。问能否经有限步让所有数都等于均值 $A=\frac1n\sum a_i$；能的话求一条操作序列，并尽量求最少步数。

# 已知判定条件（直接使用）

- $n\le2$ 恒可；$n=3$ 当且仅当成等差数列；$n=4$ 恒可。
- $n\ge4$：令 $S=\sum a_i$，$d_i=na_i-S$，$g=\gcd(d_1,\dots,d_n)$，$e_i=d_i/g$，$G=\gcd_{i<j}|e_i-e_j|$。
  可平均 $\iff$ $G$ 是 2 的幂。

（注意：$n=3$ 必须用等差判据，$G$ 判据会误判；计算用精确分数/大整数。）

# 开放状态

一般情形的最小步数**尚无已知多项式算法（本项目未解决其复杂度）**，是否 NP-hard 也未定。给有证明的下界和已验证的构造上界即可；全局 $n-1$ 不是合法通用下界（解可能拆成多个零和分量），不要宣称"最优"是已知结论。
