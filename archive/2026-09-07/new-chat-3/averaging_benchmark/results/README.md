# Evaluation artifacts

Current migration records:
- `migration_report.json`: reproducible algorithm evaluation; generated by `src/eval_all.py`.
- `migration_python_tests.log`: Python regression run (including timeout/cap/API/data upgrade tests).
- `migration_web_tests.log`: Node regression and concatenated Worker tests.
- `migration_browser_tests.log`: real Chromium end-to-end run, including no external network requests.
- `migration_mobile.png`: Chromium 390px viewport screenshot.
- `migration_upgrade.log`: full data upgrade counts/budgets.
- `current_test.jsonl`, `current_construct.*`, `current_judge.*`: non-oracle predictions and scores for the current test split.

`sample_*`, `cons_oracle`, `min_oracle` and earlier files are historical artifacts for
an older dataset/implementation. Do not use them as performance claims for v3.
