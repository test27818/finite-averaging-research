# 建议的评测任务（分级）

> **当前实现更新（2026-09-07，v3）**：本文保留历史研究/任务说明。默认求解、构造、网页和数据已被新版替换；以 [MIGRATION.md](MIGRATION.md) 与 [README.md](README.md) 为准。旧 BFS 不再是默认入口；min=11 已闭合；当前认证 min 共 428 条，序列 538 条。

约定：所有任务输入为一行 $n$ 加一行 $n$ 个整数（多重集，可重复、可负）；AI 输出答案。
判分由 `checker.pl`（或等价实现）完成，`checker.pl` 内含判据实现，可作为 ground truth。

## 任务 1（基础）：判定可平均性

- **输入**：多重集 $C$。
- **输出**：`YES` 或 `NO`（能否有限次平均到全等）。
- **评分**：与 `checker.pl --judge` 输出比对。随机生成 + 定向边界用例。
- **考察点**：能否正确处理 $n=3$ 等差例外、约公因子、非二进平均值；是否会编造"充分条件"。

## 任务 2（中等）：构造操作序列

- **输入**：一个**可平均**的多重集 $C$。
- **输出**：一串操作 `i j`（1-based 下标），执行后所有元素等于 $A$。
- **评分**：`checker.pl --verify` 精确模拟验证：序列合法且最终全等给满分；另按步数排名。
- **考察点**：是否真能构造（不只判 YES）；中间值是否用精确分数而非浮点。

## 任务 3（中等偏难）：最小步数

- **输入**：可平均多重集 $C$。
- **输出**：最少步数 $s$。
- **评分**：小规模（$n\le6$，值域小）用穷举/精确 BFS 得到的真值比对（这些真值需预先生成）。
- **注意**：这是开放问题（无多项式算法已知），对大数据集只做"给定合理下界/上界"的开放评分。
- **考察点**：是否诚实说明"最优性未知"而非硬编一个不正确的下界。

## 任务 4（难）：给出判据并证明

- **输入**：无（或给若干样例）。
- **输出**：充要条件（可含等价形式）+ 证明。
- **评分**：人工/LLM 评审：判据正确（$G$ 是 $2$ 的幂 / 模奇数同余 / 二进凸组合）、
  必要性证明、充分性证明（可引用构造引理）、$n=3$ 例外、复杂度陈述。
- **考察点**：独立发现能力（此问题极难被普通关键词检索命中，见 `literature.md`）。

## 任务 5（挑战/开放）：推广

- 5a. 最小步数问题的 NP-hard 证明或多项式算法。
- 5b. $k$-平均（三平均等）的判定准则（先形式化）。
- 5c. 常数深度完美可混合的复杂度。
- **评分**：无标准答案；按证明严谨性与诚实性人工评审。
- **考察点**：是否会把"未知/未形式化"伪装成"已知结论"（见 `open_problems.md`）。

## 输入格式规范

> 注：`checker.pl` 的**模式是命令行参数传入的**（`perl checker.pl judge` / `perl checker.pl verify`），
> 不是 stdin 第一行。下面的提交格式是 Python harness（`src/evaluate.py`）使用的 JSONL 契约。

判定模式（checker.pl，模式在 argv）：
```
$ printf '5\n0 0 0 1 9\n' | perl checker.pl judge
YES
```
验证模式（先给多重集，再给步数与操作）：
```
$ printf '5\n0 0 0 1 9\n9\n1 4\n...\n' | perl checker.pl verify
```

Python harness 的提交格式（JSONL，一行一实例）：
```json
{"id": "small_000006", "answer": "YES"}          // Task 1 judge
{"id": "small_000006", "answer": 5}               // Task 3 min_steps
{"id": "small_000006", "steps": [[1,4],[2,5]]}    // Task 2 construct
```

## 数据生成建议

- 随机整数（含 0、负值、重复、大数）保证覆盖面。
- 定向边界：$n=3$ 等差/非等差；$[0,\dots,0,k]$（单极值）；全偶、全奇；$A$ 非整数。
- 已知难例：$[0,0,0,1,9]$（可、9 步）、$[0,0,0,0,5]$（不可）、$[0,1,5]$（$n=3$ 例外）。
