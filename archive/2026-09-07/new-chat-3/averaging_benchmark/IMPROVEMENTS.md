## 1. 三个子问题的瓶颈完全不同

| 子问题 | 现状 | 判断 |
|---|---|---|
| Task 1 判定 | `solver.judge()`：归一化偏差 + 两两差 gcd 是否为 2 的幂 | **没有提升空间**。$O(n)$ 次 gcd、任意精度、$O(N^2)$；两遍 gcd（$g$ 与 $G$）都是必需的，也没有可靠的提前退出条件 |
| Task 2 构造 | $n\le6$ BFS；$n=2^k$ 用 `power2_tree`；JS 里的随机贪心实测不收敛 | **缺口最大**：文献 Thm 1.1(c) 的通用构造没实现，$n$ 非 2 的幂就基本给不出序列（`DESIGN.md` §6 已自认） |
| Task 3 最少步数 | Fraction 裸 BFS（带 `max_den_exp=12` 截断）+ 手搓特例 + CP-SAT | **不是问题难，是表示与编码选错了**（§2、§3、§5） |

Task 3 现有实现的四条具体毛病：

1. **状态表示错**：目标是"偏差全 0"，而**整体乘非零有理数是动力系统的对称**；用 `Fraction`
   元组当状态，等于把同一个形状按 $1,1/2,1/4,1/8,\dots$ 复制成无数个点。这才是实测 ×13/层
   爆炸的主因。
2. **静默不完备**：`max_den_exp` 一砍，BFS 返回 `None`，与"不可平均"混在一起；
   `case_study.md` §9 自己撞到（6 元块需要分母 ≥ 8）。
3. **没有可用下界**：只有 $n-1$ 与 $\lceil nz/2\rceil$，夹逼永远差一口气，只能靠手写
   "零值计数 + ±可配穷举"（而且 $n-1$ 这个"连通下界"写法本身就不严谨，见 §7.3）。
4. **CP-SAT 编码错**：把 $\div2$ 塞进整数线性算术再把变量整体放大 $2^K$，域巨大、传播极弱（§5）。

## 2. 核心改进：投影整数状态 + A\* + 分块分支限界（`solver_v2.py`）

偏差 $x_i=n a_i-S$（整数、和 0），目标 = 零向量，一步 $(x_i,x_j)\to(x_i+x_j)/2$。
缩放是对称 ⇒ 每步"全乘 2、再除总 gcd"，得到**纯整数、无除法**的等价系统：

```
x_i, x_j <- x_i + x_j ;   x_k <- 2 x_k (k∉{i,j}) ;   然后 / gcd(x)
```

于是：状态永远是**原整数向量**（位长被输入界住，不再需要 `max_den_exp`，**不完备性消失**）；
状态键 = 排序 + 原素化 + 变号商（三重对称一次性折叠）；改用 **A\***（可采纳启发式：
非零数/2、"无相反数对必须先 setup"、不同绝对值数/2）；并且 limit 模式一旦前沿耗尽
就产出 **"不存在 ≤K 步解"的证书**。再叠上分块定理
$\min(\text{全})=\min_{\text{零和划分}}\sum_B\min(B)$ 的子集 DP ⇒ 把 $n=10$ 自动切成 4+6。

## 3. 新下界：κ / 深度过程界（`lower.py`）—— 把"证下界"变成一次计算

跟踪血统权重：位置 $i$ 的终值 $=\big(\sum_j m_jx_j\big)/2^{h_i}$，$m\ge0$ 整数、
$\sum_j m_j\le 2^{h_i}$、$m_i\ge1$，$h_i$ 是其血统 DAG 深度；一步 $\{i,j\}$ 把两个深度变成
$\max(h_i,h_j)+1$。定义

$$\kappa_i=\min\{h:\exists m\ge0,\ m_i\ge1,\ \textstyle\sum_j m_j\le2^h,\ \sum_j m_jx_j=0\},\qquad
D(\kappa)=\text{深度过程达到 }\kappa\text{ 的最少步数}\ \Rightarrow\ T\ge D(\kappa).$$

$\kappa_i$ 用"恰好 $t$ 项能否凑出 0"的位集 DP（窗口 $\max|x|\cdot2^h$ 位，实现里对超大值自动
收缩 $h$、必要时放弃），$D(\kappa)$ 是类型计数向量上的一个小 BFS。再和"零和分块 DP"
（块代价 $\max(\lvert B\rvert-1,h(B),D(\kappa(B)))$）取 max。

* **强度**：78 个有真值的实例里 **49 个（62.8%）光靠下界就等于真值**，平均 0.5 ms/例、零搜索
  （连 `[1,3,5,7,9]` 这种"解会分裂成两个零和对子"的实例也被 $D(\kappa)$+分块 DP 精确认证为 2）。
  这正是 v2 能在 $n\le8$ 上几乎全认证的原因——搜索只需补剩下的 36%。
* **可靠性**：78 例真值 + 两个案例上 **0 例 LB>真值**。
* **过程教训（值得写进 `case_study.md` 的陷阱表）**：我先后推出三个"看着很像"的错界——
  ① $T\ge\frac12\sum_i\kappa_i$（**假**：$[0,0,0,1]$ 的 $\kappa=(2,2,2,2)$ 给 4，真值 3，
  因为一步能把两个深度不等的位置同时抬很高）；② $h_i\le k_i$（**假**：位置只参与 1 次也可能
  继承深度 2 的血统）；③ 全局 $(\text{非零数})-1$ 连通界（**假**：忽略解可分裂成多个零和分量，
  $[1,3,5,7,9]$ 真值 2）。全部是被"跑一遍与真值对比"抓出来的。**下界这种东西必须实测校验。**
* **已知弱点 + 由此冒出的一个新猜想**：对**不可分解的 generic 实例**（无非平凡零和子集 ⇒
  零和关系只有 $(1,\dots,1)$ 的倍数），$\kappa_i=\lceil\log_2 n\rceil$、$D(\kappa)=n-1$，
  界退化回连通下界，而蝴蝶结构给的上界是 $\frac n2\log_2 n$（$n=8$：LB 7 vs UB 12，v2 30 s 内判定不了）。
  但每个位置的终值权重**必须**恰好是 $(1/n,\dots,1/n)$（因为没有别的零和关系），
  而"两行平均后变一致"要求两行在互不相交、等大的支撑上各自一致 ⇒
  **猜想：generic 且 $n=2^t$ 时 $\min=\frac n2\log_2 n$，即蝴蝶结构精确最优。**
  实测支持：$n=4$ 的 generic 实例 min $=4=\frac42\log_2 4$ **恰好等于蝴蝶结构**
  （`[4,2,-5,-1]`、`[-5,6,1,-2]`、`[-4,-5,1,-2]`，BFS / CP-SAT / v2 三方一致），
  而结构化实例 `[0,0,0,1]` 只需 3 步 $<4$；$n=8$ generic 目前是 $[7,12]$ 的开区间
  （v2 30 s 内合不上）。**这本身就是给 benchmark 加难度层的现成题**：
  "generic（无零和子集）实例的最少步数" 比"有分解的实例"更难认证。
  要把猜想变成定理，需要排除"非一致权重行经多次平均后恰好变一致"的路径
  —— 一条现成的、便宜可验证的开放题（建议加进 `open_problems.md` 当 OP6）。

## 4. Task 2 构造：`construct.py`（把文献引理 6 变成能跑的算法）

Lemma 6 的证明本身就是算法：在**整数、均值 0、块大小 $2^t$** 的配置上，
只要还存在两个不同的同奇偶值就把它们平均，则 $\Psi=\sum x_i^2$ 每步严格下降（下降 $\ge2$），
且"整数+均值 0+大小 $2^t$"不变；无合法对时只剩 $\le2$ 个不同值，那时两值必同奇偶
⇒ 只能已经全等。**所以它必然收敛**，且精度 0、无需构造划分。

实测（$n=2^t$，随机 $\pm10^6$ 值，每档 12 例）：

| $n$ | 同奇偶贪心 平均混合器 | 蝴蝶结构 `power2_tree` | 比值 | 收敛 |
|---|---|---|---|---|
| 4 | 4.3 | 4 | 1.08 | 12/12 |
| 8 | 16.2 | 12 | 1.35 | 12/12 |
| 16 | 58.9 | 32 | 1.84 | 12/12 |
| 32 | 245 | 80 | 3.06 | 12/12 |
| 128 | 810 | 448 | 1.81 | 12/12 |

结论：**贪心保证了"能构造"，但没保证"省混合器"**（对 generic 大值实例蝴蝶结构更省，
这与"蝴蝶结构非最优"的直觉相反）。所以 `construct.py` 的策略是**四路并跑取最优 + 一律精确验证**：
$n=2^t$ 整块（同奇偶贪心 / 蝴蝶结构）→ `near_final_dp`（$\le22$ 精确 2 的幂分块）→
随机打包 → 任意零和分块（小块用 §2 的 A\* 求**最优**序列，大块用同奇偶贪心）→ 整体贪心兜底。
已验证样例：`[0,0,0,1]`→3 步（蝴蝶要 4 步，且 3=最优）、`[0,0,0,1,9]`→9 步（=最优）、
例 2→11 步（=最优，见 §2b 的证书）。

## 5. SAT/CP 侧：换成无除法编码（`decide_sat2.py`）

把 $y_i(t)=2^t\cdot$值 直接当变量，一步变成**纯加法**
$y_i(t{+}1)=y_j(t{+}1)=y_i+y_j$、$y_p(t{+}1)=2y_p$，目标 $y(K)=0$；与现有
"$2\cdot half=v_i+v_j$ + 域放大 $2^K$" 的写法（模型 A）对照：

| 实例 | 模型 A（÷2 + $2^K$ 缩放） | 模型 B（无除法加法） |
|---|---|---|
| 6 元块，$K=6$（应 UNSAT） | INFEASIBLE，1.7 s，27k 分支 / 12.5k 冲突 | INFEASIBLE，2.1 s，36k 分支 / 7.4k 冲突 |
| 例 1，$K=9$（应 UNSAT） | UNKNOWN（200 s，201k 分支 / 54.9k 冲突） | UNKNOWN（177 s，**66.9k 分支 / 6.2k 冲突**） |

即：编码方向是对的（冲突数降 9×、分支数降 3×），但 CP-SAT 仍远不如专用 A\*
（同一个 $K=9$ 判定，v2 用 21 s、21k 出队给出证书）。**建议：这条线要么彻底换成
位向量 SAT + 对称破缺，要么干脆放弃通用求解器，把 A\* 的 limit 模式当"证书生成器"用。**
