# 素数平均：从例子到完整证明

先读 **[PDF讲义](prime_average_lecture.pdf)**。这是面向数学本科生的通俗展开版，沿用用户提供的原讲义，重写18讲的说明、过渡和算例，保留其正式证明与完整数表。

## 怎样读

前两讲用实际数值解释问题和G障碍；第3—5讲讲整数下降与含零收尾；第6讲说明如何安全地整理块；第7—9讲从二阶矩阵、允许分母到同余子群与精确输送；后半部逐个讲清不同库存下的真实构造及有限证书。

每个主要工具先说明“要解决什么”，再给具体算例，随后保留正式命题及证明。第一次可沿新写的解释走，第二次再核对完整公式。技术构造没有以随机测试或一句总结替代。

特别适合先手算的地方：

- 第2讲：一次错误平均如何制造新的不可解障碍。
- 第5讲：十五元五平均的三行表如何成为剪切。
- 第8讲：同余相同的两列如何被明确矩阵精确连接。
- 第9讲：同一个模五输入类产生四种本原化内容，以及平方层误差的线性修正。
- 第10讲：十一元五平均的两组完整库存。
- 第11讲：五平均十二元的两次CRT具体计算。
- 第13讲：十一平均三十四元，从计数到矩阵再到剪切。
- 第14讲：负的计数参数为何可以给非负实际取数。
- 第16讲：八元下降、十元二次多项式的逐项计算。

## 完整性与版本关系

原讲义的65个正式块（命题、附带证明、定义和正式例子）全部纳入，四组长表完整保留。唯一正式块文字修正是原宽维数公式中裸写的 `quad` 改成LaTeX间距命令。原包引用过的所有标签均有对应位置。细目见 [内容对应](内容对应.md) 和 `preservation_manifest.json`。

新增解释与算例经过精确算术检查，见 `example_checks.json`。这些检查不构成全研究结果的独立数学审稿；原讲义中外部算术群定理与有限计算证书的证据级别仍按原材料保留。

原始ZIP、其他AI的工作目录和旧论文版本均未改动。

## 文件与编译

- `prime_average_lecture.pdf`：阅读成品。
- `prime_average_lecture.tex`：分章LaTeX入口。
- `chapters/`、`preface.tex`、`preamble.tex`、`references.tex`：全部可编辑源。
- `prime_average_lecture_single.tex`：已经展开的单文件LaTeX；编译不依赖其他章节文件。
- `data/`：原讲义的有限数据与核验程序，逐字节保留。
- `check_examples.py`：只使用标准库，核对本版新增的具体算例。
- `compile.py`：用XeLaTeX连续编译三次，不执行数学验证。
- `VALIDATION.json`：完整性、编译与原包未变检查结果。

运行 `python compile.py` 即可编译。需要XeLaTeX（MiKTeX或TeX Live）；字体为Times New Roman、宋体、黑体、楷体和微软雅黑，其他系统可在 `preamble.tex` 中替换。现成单文件源码也可直接交给XeLaTeX。
