## 三种阅读目标

**理解主成果：** 导读第1—4章 → 三平均与素数主证明卷 → 合数与算法卷。无需先读每个旧维数的宏搜索报告。

**继续五元研究：** 导读第5章 → 阈值以下卷，依次读强制递归、范数子族、三进有理点、环面和固定模板。完整可判定性已解，简洁静态分类未解。

**核验一项结论：** 从 `EVIDENCE.md` 的ID进入其原文与核验命令。命令按原工作区根目录的约定保留，不在合集目录内盲目运行。这里只验证整理完整性，没有重跑所有数学核验。

## “完整覆盖”的准确含义

- 整理开始时，原工作区的全部文件均复制到 `sources/`，维持相同目录层级，并记录SHA256；包含原文之间重复甚至矛盾的历史阶段。
- 全部 Markdown 在正文分卷中各主收录一次；公式、例子、失败路线和证明段落不删减。为了在新位置跳转，汇编正文只重写可识别且存在的本地链接；逐字节原样版本始终在 `sources/`。
- 新写导读是解释与阅读组织，不替代完整证明。这里没有宣称把所有历史稿消歧成一篇自包含且重新认证的论文。
- 原文继承的断链、含糊文件引用和外部不可用网址不会被无声修复或当成有效证明；本地目标问题单独报告。
- 全部 TeX/PDF/脚本/证书保持原样可访问，不把未读取的PDF冒充已编辑的正文。
