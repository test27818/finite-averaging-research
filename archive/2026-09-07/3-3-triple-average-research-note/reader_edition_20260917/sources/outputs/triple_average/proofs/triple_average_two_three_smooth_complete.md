# 全部二三光滑维数的完整判据

**接口进一步加强：** [所有偶维 B 核减半](../history/triple_average_all_even_B_kernel_halving.md) 现将核内结论扩展到任意偶数 \(n\ge14\)。本页的八整除模板与二三光滑归纳仍完整有效；较强的核内桥仍不自动证明任意偶维输入可解。

## 1. 主定理

**定理。** 对所有
\[
n=2^a3^b\ge7,\qquad a,b\ge0,
\]
有限步三平均可达当且仅当中心化、本原化后的 G 是三的幂。全等输入直接可达。

这新增了十六元、三十二元、六十四元等全部二的幂及其三进塔，补齐此前十二元、十八元和八元之间的二进方向。最小未解维数现为17，一般任意 n 的判据仍未证明。

核心是下面适用于任何 \(8\mid n,\ n\ge16\) 的 B 核减半引理；引理本身甚至允许 n 有其他奇素因子。它调用已证明的十二元定理，不要求这些核独立生成算术群。

## 2. 一个统一的减半模板

**引理。** 设 \(8\mid n,\ n\ge16\)。任意合法
\[
\mathcal B_n(u,v)=(u^{n-4},v^3,w),\qquad w=-(n-4)u-3v
\]
可以经过一次真实三平均和一个合法十二元子问题，变为重数全偶的零和状态。将重数减半后得到一个合法的 \(n/2\) 元状态。

取本原整数参数 \(\gcd(u,v)=1\)。合法性为
\(\gcd(u-v,n)\) 是三幂，所以 u、v 奇偶相反，且对每个非三素数 \(p\mid n\)，\(u-v\) 模 p 非零。

先平均 \((w,u,v)\)，得到
\[
a=-\frac{(n-5)u+2v}{3}.
\]
完整状态成为
\[
(u^{n-5},v^2,a^3).
\]
选择十二元子块
\[
C=(u^9,v^2,a).
\]
位置数足够，因为 \(n-5\ge11\)。其均值为
\[
\mu=\frac{9u+2v+a}{12}
=\frac{(32-n)u+4v}{36}
=\frac{(8-n/4)u+v}{9}\in\mathbb Z[1/3].
\tag{1}
\]
C 含 u、v 两种奇偶，而目标均值仅含三进分母；中心化、清分母后仍有奇偶差异。因此十二元子问题本原 G 是1或3，满足[十二元完整定理](../arithmetic_cases/triple_average_twelve_arithmetic_complete.md)的全部条件。

只在 C 内执行其有限三平均路径，把十二个位置归并为 \(\mu^{12}\)。输出为
\[
(\mu^{12},u^{n-14},a^2).
\tag{2}
\]
全部重数是偶数，且总和仍零。每种重数减半得到
\[
Y=(\mu^6,u^{n/2-7},a),\qquad \sum Y=0.
\tag{3}
\]

## 3. 压缩后没有丢失局部合法性

式 (3) 中 u 仍至少有一个位置，且
\[
\mu-u=\frac{v-(1+n/4)u}{9}.
\tag{4}
\]
若 p 是 \(n/2\) 的奇非三素因子，则 \(p\mid n/4\)，所以
\[
\mu-u\equiv(v-u)/9\ne0\pmod p.
\]
若 p=2，因为 \(8\mid n\)，n/4为偶数，同一个非零余数关系仍成立。
清除三进分母、本原化都不会消除这两个值的差异；本原 G 又整除 \(n/2\)，故它只能是三幂。引理得证。

若已经知道 \(n/2\) 元的完整判据，则把 (2) 的相同值副本均分到两个不交的 Y，分别执行其归零路径，便解决原 B_n 状态。不执行二平均，也不添加任何新位置。

## 4. 二三光滑维数的归纳

n 的非三素数只有2时，已有[单危险素数归约](../history/triple_average_isolated_prime_reduction.md)把任意合法输入有限步送入 B_n。也可使用更强的[图论核心界](../history/triple_average_blocker_graph_core.md)：d至多1时，至少有 n-3 重值，直接满足该桥的重数需要。

固定 b，对 a 归纳：

- a=0：三幂维数有固定张量网络；
- a=1 且 n至少7：b至少2，属于已证明的[十八元三进塔](../arithmetic_cases/triple_average_eighteen_via_twelve_complete.md)；
- a=2 且 n至少7：b至少1，属于十二元三进塔；
- a=3：属于已证明的八元三进塔；
- a至少4：先进入 B_n，再用第2--3节减半到 \(2^{a-1}3^b\)，调用归纳假设。

所有调用都有严格更小的外部位置数，且十二元子程序已经独立证明。因此不存在依赖循环。每一层只用真实三平均、已证子问题和重数分配，有限可达性由归纳得到。

对 n=16，(3) 恰为合法八元状态 \((\mu^6,u,a)\)。因此十六元不需要新的宏词群或新的大规模有限覆盖证书。

## 5. 算法与证据边界

任意二三光滑 n 的判定只需规范化并求 gcd，是总输入位长的多项式时间算法。
本文不声称显式输出所有原子平均词具有统一多项式长度：安全能量下降的步数与已证子程序内部路径仍需独立控制。

work/verify_dyadic_kernel_halving.py 逐条核对原子预备操作、十二元局部判据、均值公式、输出重数、总和及压缩后 G，使用至多四种不同值的计数，不展开大型 n 维数组。测试包含15个维数，最大为27648；另把计数版 G 与完整中心化算法对照。

最初的96类模16／模5搜索在 work/search_sixteen_halving_bridge.py 中保留发现过程。其一条模板实际上覆盖全部合法类型，最终证明已化为上面的全称公式，不依赖96类枚举的完备性。十二元调用的内部路径由独立定理承担，不能把直接赋均值记成一次原子平均。
