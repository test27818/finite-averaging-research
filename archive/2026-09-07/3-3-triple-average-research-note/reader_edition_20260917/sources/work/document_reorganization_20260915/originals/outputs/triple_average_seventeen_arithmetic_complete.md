# 十七元完整判据：正向逆元、级17同余子群与唯一合法尖点

日期：2026-09-10。

## 1. 结论与证明链

**定理。** 非恒等十七元有理状态中心化、清分母并本原化后，有限步三平均可归零，当且仅当 G=1。结合[一般三进塔传播定理](triple_average_general_n_synthesis.md)第5节，全部 n=17*3^k 中，G 为三幂是充要条件。

因此这些维数有输入总位长的多项式时间判定。没有同时声称输出平均路径具有多项式长度。本结果将当时最小未解维数由17推进到19；[后续十九元证明](triple_average_nineteen_arithmetic_complete.md)已进一步完成十九元，最新总状态见交接说明。任意n的判据仍开放。

充分性的证明链是：
\[
X\ \longrightarrow\ (u^{14},a,b,c)
\ \longrightarrow\ B_{17}(u,v)
\ \xrightarrow{\ H\ }\ B_{17}(0,1)
\ \longrightarrow\ 0,
\]
允许途中整体尺度随真实宏改变。H 是一组正向可实现整数矩阵生成的子群，精确等于 Gamma_0(17) 的一个有理共轭。

本证明解决了前一阶段“预备返回可能增长”的困难：用已实现的群轨道归约代替未能闭合的逐次本原范数下降。原净下降实验的边界仍保留，未被改写成全覆盖。

## 2. 一般输入进入标准核

对本原零和整数 X，G 整除17，所以合法性等价于坐标模17不全相同。

反复选择非恒等、和被3整除、且补集仍保留模17差异的三元组。每次产生整数状态、保持合法性并严格降低平方和；必要的本原约分进一步降低平方和，故过程有限终止。

终止时，[危险图核心定理](triple_average_blocker_graph_core.md)给出至少 n-d-2>=14 个相同值，因为非三危险素数至多一个。因此可写为 (u^14,a,b,c)。合法性保证三个例外中有一个模17不同于u，重标记为c。平均 (u,a,b)，得到
\[
(u^{13},v^3,c),\qquad v=(u+a+b)/3,
\qquad c=-13u-3v.
\]
保留的u与c仍不同余，故输出本原 B17 合法。这一步允许三进分母，不要求新的均值为整数。

对本原整数参数 gcd(u,v)=1，有
\[
G(B_{17}(u,v))=\gcd(u-v,17).
\tag{1}
\]

## 4. 正向逆元确实存在

原子宏满足精确的物理尺度恒等式：以下词均按时间顺序书写，lambda=-3^(-8)：
\[
PQPQ=\lambda I,\qquad
BQTBQT=\lambda I,\qquad
AQUAQU=\lambda I.
\tag{3}
\]
例如整数矩阵
\[
\widehat T\widehat Q\widehat B
=\begin{pmatrix}270&81\\-909&-270\end{pmatrix},
\qquad (\widehat T\widehat Q\widehat B)^2=-729I.
\]
加入各自实际三进尺度后即得(3)。因此每个生成元的射影逆都由正向词实现：

| 形式逆元 | 正向词 |
|---|---|
| A^-1 | QUAQU |
| B^-1 | QTBQT |
| P^-1 | QPQ |
| Q^-1 | UAQUA |
| T^-1 | BQTBQ |
| U^-1 | AQUAQ |

每条正向词的实际矩阵为 lambda 乘以相应实际生成元的逆。A、B 的逆词分别为55、61次原子平均。负的整体尺度不是额外操作，而是词本身的真实结果；它不影响射影轨道和最终归零。

此前“旧通用库不含 B 的固定逆词”的证明仍然正确，其对象仅为旧六宏库。新 Q、T、U 经更多中间分层产生，打破了旧库的模3不变集。

## 5. 六个整数生成元与18陪集证书

小写字母表示上表已经正向实现的逆元，词仍按时间顺序。下列矩阵属于真实正向射影群：

| 词 | 整数矩阵 |
|---|---|
| uQa | [[-9,-2],[5,1]] |
| pUa | [[-5,-1],[-19,-4]] |
| auq | [[-3,-1],[10,3]] |
| QQ | [[-9,-1],[37,4]] |
| qUA | [[-25,-6],[71,17]] |
| bUAbQ | [[-56,-15],[239,64]] |

令H为这些矩阵生成的 PSL2(Z) 子群。每个生成元行列式为1，并满足
\[
a+b-c-d=0\pmod{17}.
\]
因此
\[
H\subseteq H_{17}:=
\left\{\begin{pmatrix}a&b\\c&d\end{pmatrix}\in PSL_2(\mathbb Z):
a+b=c+d\pmod{17}\right\}.
\tag{4}
\]
H_17是直线[1:1]的稳定子。取 C=[[1,0],[1,1]]，则
\[
H_{17}=C\Gamma_0(17)C^{-1},\qquad [PSL_2(\mathbb Z):H_{17}]=18.
\]

对六个生成元作 PSL2(Z)=C2*C3 的精确子群折叠，得到18个完整陪集。独立地从基标签[1:-1]出发，用行向量右乘 S、U 的模17作用标记，恰好得到 P1(F17) 的18个不同标签，且所有边一致。因此
\[
\boxed{H=H_{17}\subseteq\Gamma_{17}^{+}.}
\tag{5}
\]
这是充分子群的等式，不宣称全部三进返回群等于H。证书仅包含六条矩阵词和18个陪集，无须扩大有限模像来推断指数。

## 6. 唯一合法尖点与终止

H有两个有理尖点，宽度为1、17；前者是 u=v mod17 的不合法方向，后者包含全部合法本原参数。可以直接用 Bezout 恒等式证明最后一句，而不依赖数值轨道采样。

给定 gcd(u,v)=1 且17不整除u-v，先取 c0*u+d0*v=1，再令
\[
k=(v-u-c_0-d_0)(v-u)^{-1}\pmod{17},
\quad c=c_0+vk,\quad d=d_0-uk.
\]
则
\[
h=\begin{pmatrix}v&-u\\c&d\end{pmatrix}\in H_{17}=H,
\qquad h\binom uv=\binom01.
\tag{6}
\]
H由已经正向实现的六个整数生成元及其逆生成，因此h有有限正向宏实现，实际输出可以带非零整体尺度。

B17(0,1)=(0^13,1^3,-3)。选其中五个零及四个非零位置，执行九元标准网络，六次原子平均后全部归零。由齐次性，任何非零尺度的同一终端均可归零。

(1)--(6)与第2节共同证明十七元完整充分性。必要性是既有的非三素数公共余数不变量。

## 7. 自守与S-算术解释

这里同时出现两个不同而相容的算术对象：

1. B 在 (x,y)=(u,4u+v) 下是虚二次域 Q(sqrt(-2)) 中范数3素元的乘法。新的正向逆词首次实现了其共轭素元方向；此前静态 theta 的两个分支现在都有真实正向实现。
2. 全部参数的收尾使用分裂群 SL2 的同余子群 Gamma_0(17)。模曲线 X_0(17) 的两个尖点中只有一个合法；其属为1，椭圆点数分别为2、0。

还能构造真实初等矩阵。按实际矩阵的形式群乘积，设
\[
K=TQ^{-1}A^2=
\begin{pmatrix}1&0\\2/3&1/3\end{pmatrix},
\quad A^{-2}K^2=\begin{pmatrix}1&0\\34&1\end{pmatrix}.
\tag{7}
\]
将逆元替换为正向词，后者有234步原子证书，实际尺度为3^(-32)。K的共轭产生参数34/3^j的平移，故群包含全部下三角初等矩阵 E21(34R)。

再用B共轭，并以 [[2,0],[-9,1]] 换基，得到 E21(68R) 与 E12(68R) 两族相对根群。这个S-算术包含是精确矩阵结论；本次完整证明采用更直接的18陪集证书，不需要另行援引未经核对的一般算术性定理。

## 8. 可推广的同余子群目标

这一收尾论证对任意 n>=9 有统一表述。令 N=n/3^(v_3(n))。本原 B_n 的合法性为 gcd(u-v,N)=1；若其真实正向返回群包含
\[
C\Gamma_0(N)C^{-1},\qquad C=\begin{pmatrix}1&0\\1&1\end{pmatrix},
\tag{8}
\]
则同一 Bezout 构造把全部合法参数送到(0,1)，再用九元零填充收尾。因此(8)足以解决完整 B_n，不需要逐一猜测合法 cusp 代表。

当 n 只有一个非三素因子时，第2节的安全核心与单例外见证桥仍适用；多危险素数的一般输入还需要独立的标准核接口。(8)在任意n上的正向生成尚未证明，所以本文没有解决任意n。
