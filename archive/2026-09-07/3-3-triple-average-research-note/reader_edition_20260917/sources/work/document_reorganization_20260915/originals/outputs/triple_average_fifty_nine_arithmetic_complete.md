# 59元完整判据与跨维数结构

日期：2026-09-10。

## 定理

59元有理输入中心化、本原化后可有限步三平均归零，当且仅当G=1。
必要性是公共非零模59余数不变量。充分性如下。

## 正向群资源

一次额外原子模板库中两个固定宏满足(BA)^2=(16/3^14)I，启动正向逆闭包。
预算受控的两字母侧词激活给出33个固定无环可逆节点；每个模板及子调用域均已独立物理重放。

同第一行与同倍率分组产生L(59/12)。六个下三角仿射倍率进一步给出
L(59R)，R=Z[1/(2*3*5*7*11*17*19*23)]。
目标R_59(1/27)由迹根公式获得正向逆。

换到C=[[1,0],[1,1]]基，节点1、8经L(118/21)消去左下项后具有同倍率3/49，其商为U(49/81)。
反向共轭得到U(1/27)，重复27次得到U(1)。
节点7消元后的倍率为2/2187。由共轭与整数相减依次构造
U(1/2)、U(1/4)、U(1/8)，故得到U(-7/8)。

**坐标勘误及替代证明。** 原稿在此将C基的U(-7/8)与原B基的G、A_0混乘。
该数值迹零并不是可执行词的证明；换到同一C基后迹为-511/8，不是0。
撤回以此得到标准宏逆的论证。完整59元判据使用以下独立替代链，不依赖标准宏逆。

\[
d_1=3/49,\qquad d_5=-7/243,\qquad d_1d_5^2=3^{-9}.
\]

先由U(1)及已证上三角仿射元F_1、F_7的正反共轭，得到
U(Z[1/(2*3*7)])。严格理由是参数加法群包含Z[d_1,d_1^{-1},d_7,d_7^{-1}]，
d_7=2/2187；互素分子分母的Bezout恒等式使该环恰为Z[1/(2*3*7)]。
因此F_1和F_5右乘U(-b_i)可消去其上右条目，其中b_1=1/21、b_5=4/81。
得到可执行Q_1=diag(1,3/49)、Q_5=diag(1,-7/243)，
Q_1Q_5^2=diag(1,3^{-9})。
这整个构造始终在C基中进行，没有混用原基矩阵。
其偶数幂在射影意义下给出D(epsilon)，epsilon=+-3^{9j}。

## 完整同余与终端

完整Schreier横截集有60个陪集、21个非平凡回路。每个回路都存在epsilon=+-3^{9j}使(epsilon-a)/c属于Z[1/3]，从而分解为

\[
U(-t)L(c/\epsilon)D(\epsilon)U(w).
\]

所以真实正向群包含共轭Gamma_0(59)，不是只具有相同有限模像。
统一标准核入口把任意合法59元输入送入B_59；Bézout公式再送到(0,1)。
B_59(0,1)=(0^55,1^3,-3)，用五个零补成九元零和块，六次三平均归零。

## 结构解释与预测

17至59的搜索结果现在显示出稳定的四层结构，而不是每个素数独立的随机证书：

1. **返回种子层。** 少量真实返回通过有限阶乘积获得正向逆。具体周期词随p变化，目前尚不能预测；它是仍未统一的物理层。
2. **根提取层。** 可逆宏按第一行方向分组，商必为仿射元；同倍率仿射元之商必为纯根。这是一般二维线性代数，可预测且已在53、59奏效。
3. **尖点与伸缩层。** R_p(t)、标准A_p和根之间有统一恒等式。奇次返回给宽度一尖点；一般返回给上三角仿射元；校正后提供局部化伸缩。这部分已不依赖逐p搜索。
4. **Schreier消元层。** 一旦上下根和三进单位到位，完整同余群及Bézout终端由统一公式处理。53、59说明不必要求c/p为单位，只需解epsilon=a mod c的主元同余。

因此下一素数不应重新从零搜索完整同余群。可预测流程应是：构造一族普遍返回；证明至少一小组返回可逆；按第一行/倍率公式提取根；最后调用统一Schreier消元。
真正尚缺的一般定理集中在第一层：为什么每个p=2 mod3都存在足够的正向可逆返回种子。
分裂素数的高斯周期用全局范数统一解决了这一层；非分裂素数需要类似的范数周期、运输半群周期，或不要求逆元的参数下降。
