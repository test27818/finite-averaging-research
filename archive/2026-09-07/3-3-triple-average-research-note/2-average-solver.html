01 / 精确判定

使用题目给定的判定条件，不重新推导其充分必要性。所有数本来相等时直接返回 0 步；该分支避免 g = 0 的除零问题。n ≤ 2 恒可；n = 3 先排序，检查是否成等差。

S = Σaᵢ；dᵢ = n·aᵢ − S
g = gcd(d₁, …, dₙ)；eᵢ = dᵢ / g
G = gcd(|e₂−e₁|, …, |eₙ−e₁|)
n ≥ 4：G > 0 且 (G & (G−1)) = 0。

差分只需固定第一项，便能求出全部两两差的 gcd，避免 O(n²) 枚举。均值是整数不代表必可平均；例如 -4, 1, 1, 1, 1 的 G = 5，仍然不可平均。

02 / 构造解，再缩短

精确状态压缩

搜索状态采用和为零、gcd 为 1 的 BigInt 整数偏差。每一步先把未选中的偏差乘 2，把选中的两项改为 x+y，再整体约去 gcd。排序后合并置换对称状态；输出时重新映射到原数组的固定索引。这不会删除原题中的数字，也不把动态排序的序号当作操作索引。

结构化收尾与下降搜索

优先直接抵消相反数，寻找零和四元组。若非零项能装入不超过 n 的 2 的幂大小的组，则借用现有零项进行蝶形平均，比较多种分组顺序并跳过无效平均。零项来自当前真实状态，绝不凭空增添元素。

其他状态优先选择仍可解、且归一化整数平方和严格减小的操作。遇到下降陷阱时，使用带深度惩罚的最佳优先搜索寻找更小平方和的状态或可直接收尾的状态。开启“不设时限”会移除逃逸搜索的展开次数上限，但仍保留 19,000 步构造保护；有限资源下不宣称对任意规模都能快速完成。

短解与最短性

均衡 / 深搜模式还会比较另一条构造路线；n = 9–24 使用束搜索尝试更短序列；n ≤ 12 在剩余优化预算内使用带可采纳下界和转置表的 IDA* 排除更短深度。束搜索不是最优算法。只有达到已证明下界，或完整排除了所有更短深度，才显示“最短已证”；其余显示已验证上界与当前已证下界。

搜索下界：令 m 为非零项数、c 为当前最多可直接抵消的相反数对数，C = ⌈m/2⌉，使用 C + max(0, ⌈(C−c)/2⌉)。最终至少需 C 次抵消；每个非抵消操作最多新增两对可抵消项，因此得到额外准备步数下界。

03 / 随机性与批量口径

用 crypto.getRandomValues 取得随机位，通过拒绝取样生成区间内无模偏差的整数。一个候选数组的 n 个元素独立均匀生成；仅依据给定判定条件筛选可解数组。绝不逆向打乱、植入序列、先生成零和题再补数，或排除重复题面。随机位来自浏览器提供的加密安全随机源，本应用不声称直接访问物理真随机硬件。

批量每个被接受的样本只调用一次求解器。求解时间包含判定、构造、优化与索引映射，不含随机筛选、独立验解或播放。整批实际用时另包含这些额外开销。最快 / 最慢 / 平均都是这一批已完成调用的单次测量；未完成构造的调用也计入耗时并单独标明。

04 / 独立验证与显示

验证器只接收原始整数数组和 1 基操作索引，从头用约分后的任意精度有理数执行。每步检查两个索引不同且合法，检查被修改两项之和守恒，最后逐项比较是否精确等于原均值。验证器不调用判定器、归一化搜索或构造路径，也不接受浮点容差。可复制到新打开的此 HTML 中再次验算。

回放保留精确分数与检查点，支持前进、后退、跳转与重播。柱图是相对均值的偏差，以初始最大偏差固定标尺；平方偏差曲线使用精确分数递推。只有最后映射为屏幕像素时才做整数定点量化。大分数可能在卡片中省略显示，悬停可查看完整值；导出不省略。

05 / 使用范围与诚实状态

支持 1–128 个整数，每项最多 256 位；批量最多 1,000 例；独立验解最多接收 20,000 步 / 例。抽样保护为每例 100,000 个候选或 30 秒。单题时限是软上限：原子运算或当前展开会略有超出；“停止”会直接终止 Worker，保留已经完成的批量结果。

“可平均”是数学判定，“找到序列”是构造成功，“独立验解通过”是证书检查，“最短已证”是最优性证明，四者分别展示。若预算用尽却没有序列，会明确显示“可平均 / 构造未完成”，不会把它误报为不可平均。指数级精确搜索不承诺大规模的全局最短解。
