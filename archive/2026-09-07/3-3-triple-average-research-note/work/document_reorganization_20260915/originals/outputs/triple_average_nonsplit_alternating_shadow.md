# 非分裂Reynolds层的完整置换影子：交错群

日期：2026-09-10。这里证明有限位置置换群的统一结构，不证明正向投影乘积含可逆元或终端。

## 1. 两个统一生成元

设p>=11为素数且p=2 mod3。物理位置为F_p，S(x)=x+1。
令tau在0、-1处固定，在其余位置取

\[
\tau(x)=-1/(x+1).
\]

由非分裂三阶轨道证明，tau有两个固定点和(p-2)/3个三循环，故tau为偶置换；S是奇长度p循环，也为偶置换。因此

\[
G_p=\langle S,\tau\rangle\subseteq A_p.
\]

## 2. 一个可预测的三循环词

置g=S^{-1}\tau。直接计算：

\[
0\mapsto-1\mapsto-2\mapsto0.
\]

对x不属于{0,-1,-2}，

\[
g(x)=-\frac{x+2}{x+1},qquad g^2(x)=x.
\]

所以

\[
\boxed{g^2=(0,-2,-1)}
\]

（循环方向随复合约定可取逆）。这不是某个p的搜索输出，而是对全部剩余素数成立的长度四词。

## 3. 生成整个A_p

不必调用Jordan定理。用S^k共轭上节三循环，得到循环相邻三循环

\[
(k,k-2,k-1),\qquad k\in F_p.
\]

线性排列上的相邻三循环a_i=(i,i+1,i+2)、0<=i<=p-3生成A_p。
可归纳证明：p=3显然；假设前p-1点上已生成A_{p-1}，再加入a_{p-3}。
当p-1>=4时A_{p-1}在不同有序点对上二重传递，共轭a_{p-3}得到所有(i,j,p-1)，它们与A_{p-1}生成A_p；小基例p=4直接核对a_0、a_1生成A_4。
故A_p包含于G_p；结合第一节的反向包含，得到

\[
\boxed{\langle S,\tau\rangle=A_p.}
\]

这是显式生成证明，不调用有限群阶枚举，也不依赖素数次数的本原群分类。事实上该相邻三循环论证只使用位置循环和长度四词。

## 4. Reynolds字母表的统一解释

基本层为

\[
Q_\tau=(I+P_\tau+P_\tau^2)/3.
\]

任意物理位置重标号sigma给出Q_{sigma tau sigma^{-1}}。
tau的循环型为1^2 3^{(p-2)/3}；这一S_p共轭类在A_p中不分裂，因为循环长度1、3都有重复。
故全部同型双载体三重划分恰是一个A_p共轭族。

这说明平移族Q_c只是完整字母表中的一个一参数切片。若平移切片没有周期，不能据此否定完整同型Reynolds半群；反过来，A_p生成性也不能推出这些幂等投影的正向乘积含逆。

## 5. 共轭平均的精确标量及其边界

A_p在F_p上的作用二重传递，零和标准表示在特征零下不可约。
对整个共轭类平均Q，结果与A_p交换，所以在零和空间上为标量。
Q在全空间的秩为r+2，r=(p-2)/3；常值方向贡献迹1，故零和迹为r+1=(p+1)/3。
于是

\[
\frac1{|\mathcal C|}\sum_{\sigma\in\mathcal C}Q_{\sigma\tau\sigma^{-1}}
\bigg|_V
=\frac{p+1}{3(p-1)}I_V.
\]

这是精确的凸标量恒等式，解释全字母表为何具有各向同性收缩。
但原操作允许复合，不允许取算子平均；这个和式不能当作真实三平均词。
它可用于设计势函数或随机控制，却不提供有限步精确归零、正向逆或标量乘积。

[固定词一致性障碍](triple_average_no_oblivious_consensus.md)进一步说明：若一个固定三平均词在整个零和空间归零，则其矩阵必须是J/p，但1/p不属于Z[1/3]。所以p>3时不可能把上述凸平均替换成一个状态无关的全空间词。统一控制必须依赖输入，或先限制到低维参数像。

## 6. 对统一证明的影响

有限群影子已经完全可预测，不再是未知：它就是A_p；Reynolds字母表是固定循环型的单一共轭类。
因此剩余问题不在“有限模像是否够大”，而在以下正半群问题：

1. 该共轭类幂等投影的有限乘积是否在某个返回核上产生非零单位；
2. 或者其奇异乘积是否统一命中零和三元组超平面；
3. 如何把凸标量的各向同性提升为有限乘积的精确算术关系。

第一项是非分裂范数周期路线，第二项是直接终端路线，第三项可能需要设计论、Hecke代数或非交换范数。
仅证明A_p或生成代数为End(V)不能替代正半群结论。
