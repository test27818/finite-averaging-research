# 二十五元完整判据：级25子群与奇数归约的最后小基例

日期：2026-09-10。

## 1. 完整结论

**定理。** 非恒等二十五元有理状态中心化、清分母并本原化后，可有限步三平均归零，当且仅当G=1。由三进提升，25*3^k维数中G为三幂是充要条件。

结合[奇数合数因子归约](triple_average_odd_composite_factor_closure.md)，这消除了奇数方向最后一个独立小基例：**如果所有素数p>=7的判据成立，则所有奇数n>=7的判据成立。** 不需要假设五元充分性，也不需要新的素数幂提升或多危险素数入口。

当前已解素数集合P={7,11,13,17,19,23}，故所有
\[
n=3^a5^b\prod_{p\in P}p^{e_p}\ge7
\]
的奇数维数均已解，指数a、b、e_p任意。8整除的相应偶数族也已由因子定理完成。最小未解维数仍为20，下一个未解素数为29。

## 2. 通用模板证书

设B25(u,v)=(u^21,v^3,-21u-3v)。本次使用的返回模板均由3或9元真实网络、一个21元子问题归并和末尾三平均构成。

每个选定的21元子块都通过**符号系数级**仿射R格包含检查，R=Z[1/3]：目标均值减锚点属于差分系数的R行模。由既有普遍模板定理，该调用对全部参数成立；21元完整判据来自七元及三进提升。

因此各宏是全参数可执行的固定线性映射，内部21元词允许依赖参数。没有将一个21元调用视为一次原子平均。完整位置重数、物理尺度和独立Fraction重放由下列文件提供：

- work/compile_bn_integer_templates.py：整系数模板及每一步尺度账本；
- work/verify_bn_integer_templates.py：独立有理系数位置重放和行模包含核验；
- work/verify_twenty_five_arithmetic_group.py：本证明用到的18个模板及其正向逆关系。

核验器明确断言全部选定模板只调用3、9、21，故不依赖任何25元结论，也不借用尚未解决的20、22元子问题。

## 4. 七个整数词与30陪集

小写字母表示上一节已经正向实现的逆元。词按时间顺序执行：

| 词 | 整数矩阵 |
|---|---|
| AIlJ | [[0,-1],[1,-2]] |
| lKi | [[-7,-1],[15,2]] |
| ACBi | [[-5,-1],[16,3]] |
| alfB | [[-11,-1],[12,1]] |
| eeNI | [[-1,0],[-25,-1]] |
| bFQABnL | [[-23,-29],[165,208]] |
| cNmeBnL | [[-41,-48],[293,343]] |

每个矩阵行列式为1，且满足a+b=c+d mod25，所以生成的H包含于
\[
H_{25}=C_0\Gamma_0(25)C_0^{-1},\qquad
C_0=\begin{pmatrix}1&0\\1&1\end{pmatrix}.
\]
对七个整数词作PSL2(Z)=C2*C3精确折叠，得到30个完整陪集。

独立标签使用P1(Z/25)，不是P1(F5)。其30个代表可取
\[
\{(1,t):0\le t<25\}\cup\{(5t,1):0\le t<5\}.
\]
从行标签[1:-1]出发，所有S、U边一致，恰遍历这30个标签。因此
\[
\boxed{H=H_{25}\subseteq\Gamma_{25}^{+}.}
\]
素数幂level在本证明中没有被降成仅模5的稳定子。H有6个cusp，宽度为25及五个1，只有宽度25的cusp合法。椭圆点数为2、0，模曲线X_0(25)属为0。

## 5. 任意输入与终端

对本原B25参数，合法性等价于5不整除u-v。取cu+dv=1，并用(c,d)->(c+vk,d-uk)调整，使c+d=v-u mod25。因为u-v在模25可逆，总可做到。于是
\[
\begin{pmatrix}v&-u\\c&d\end{pmatrix}\in H_{25}=H
\]
将参数送到(0,1)，且该矩阵有有限正向宏实现。B25(0,1)=(0^21,1^3,-3)，选其中五个零和四个非零位置执行六步九元网络即可全部归零。

一般25元输入先进行补集保留模5差异的非恒等整数安全下降。平方和严格下降，故有限停止。安全核心定理给出至少22个同值，即(u^22,a,b,c)。保留一个模5不同于u的例外c，平均(u,a,b)，进入合法B25。这完成充分性；必要性仍是G非三部分的不变量。

## 6. 证据与边界

核验入口为

    python work/run_verifications.py --id n25-complete

独立验证器重放18个通用模板及其局部格条件，检查实际标量循环、七个整数词、30陪集与独立模25标签、6个cusp、858个显式输送和446个安全核心桥。一般合法域覆盖来自Bezout公式与安全核心证明，不由样本外推。

发现阶段先用整系数编译得到235个模板，再按低阶关系和行列式筛选。最终整数词来自一个受控的四层群搜索，约1.8秒；证明只使用上面的固定七词证书，不依赖该搜索对全部宏完备。

一般素数定理和v2(n)=1、2的偶数接口仍开放。这个结果闭合的是25元以及奇数因子归约的小基例，不是任意n已经解决。
