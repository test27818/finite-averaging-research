# 非分裂素数的可预测结构：17至59证书后的综合

日期：2026-09-10。本文停止把逐素数证书当作主研究目标，区分已统一的结构与仍未统一的物理种子。

后续出现了更内生的统一对象：[载体扫掠催化器](triple_average_carrier_sweep_catalyst.md)不先指定二维返回，而从三个三重块与一个载体的固定真实操作中产生正向双向幺幂。12个可逆根的Lie闭包为sl3，局部模3、5及二进提升与十元自然稳定子一致，模20所有本原局部轨道均兼容叶碰撞终端。它把主要研究方向从“证明特定返回存在”改为“证明十位置局部算术性，并控制重叠窗口的均值运输”。混合单点返回继续作为完整但可能偏强的备选充分路线。

## 1. 已经不是随机搜索的部分

最新不依赖搜索的结构结果：[双单点等角障碍](triple_average_nonsplit_punctured_orbits.md)第7节证明，两个不同双载体划分的往返投影不可能在全零和核上为非零标量，其任意正幂也不可能。因此此前439层的阴性现象有全称几何解释，继续增加两层周期样本没有必要。

需要精确区分：根提取、迹根激活和Schreier消元的公式是统一定理，但其前提不是从“存在一些可逆种子”自动得到的。还需证明足够的第一行碰撞、非零根步长、参数理想的本原性与合适的局部化资源。分裂素数证明用范数一单位完成本原性；非分裂素数的对应全称定理仍缺。不能把统一后处理公式表述成所有种子库都会成功。

对每个剩余素数p=2 mod3，以下环节已有统一公式。

1. 任意合法输入可进入B_p(u,v)=(u^{p-4},v^3,-(p-4)u-3v)。
2. C基下合法域是p进Iwahori圆盘，整数目标为共轭Gamma_0(p)。
3. 若两个可逆宏具有相同射影第一行，其商为下三角仿射元；若两个仿射元倍率相同，其商为纯根。
4. 已有一族下根时，迹根方程t=-tr(GB)/(GB)_12是线性的，可把新宏B激活为可逆元。
5. 标准A_p与任意可逆R_p(t)满足统一上三角恒等式；奇次、偶次和一般参数版本分别产生尖点、交换或局部化根。
6. 完整Schreier横截集可由I、ST^j统一写出。每个回路只需根和单位主元消元，不需要重新猜同余群。
7. 一旦真实群覆盖合法轨道，同一个Bezout公式送到(0,1)，再由九元网络终止。

所以“根、尖点、Schreier消元”不是不同素数中的偶然现象。它们是同一个二维Iwahori控制器的三个坐标描述：根是树边稳定子的幺幂方向，尖点是边界抛物方向，Schreier回路是整数格中的全局生成账本。

陪集数始终为p+1，这是Gamma_0(p)的确定结构；终端也始终相同。宏数量和周期词形波动很大，说明它们是发现坐标，不应被猜成稳定数列。

当前唯一没有统一定理的量词是：

> 对每个p=2 mod3，原p个位置上的真实返回半群是否必含足够的非奇异周期或其他可逆种子，使根提取链能够启动？

继续证明71、83只会增加样本，不能解决这个量词。

[参数周期刚性](triple_average_parametric_cycle_rigidity.md)进一步证明：任何固定有理函数矩阵词若不在Q(p)上恒等满足有限阶迹条件，只能命中有限多个p。59元种子乘积的迹为2(2419-41p)，恰好只选中p=59。因此短周期编号和词形原则上不可由有限样本稳定预测；真正应预测的是一个随p增长的范数词或符号周期恒等式。

## 3. 可以预测的下一维数行为

非分裂轨道谱已有解析预测：[轨道文档第10节](triple_average_nonsplit_punctured_orbits.md)证明自然平移一步返回的零和迹为(chi_p(-1)-2)/3，来自(x+1)^2=-1的邻接计数。所有p=5 mod12均因整数行列式分母障碍不能让该返回的任何幂成为非零标量；这替代该子族的逐p周期试验。p=11 mod12仍需其他分析。此处排除的是一个具体返回族，不是原可达性。

同页第11节进一步给出任意非零平移c的迹公式，由两个判别式(c-1)(c+3)、(c-3)(c+1)的Legendre符号决定。c=正负3、p=11 mod12时高秩零和迹为0，但高秩迹零不推出对合；必须检查全部谱不变量。多层谱应转化为字符和/Hecke卷积，不再枚举大矩阵。

根提取现有更强的统一描述：[仿射交换子理想定理](triple_average_affine_commutator_ideal.md)证明G=<F_i>的导群恰为L(sum c_ij R)，c_ij=(1-d_j)b_i+(d_i-1)b_j。无需同倍率碰撞；只要某个交换子非零即可得到完整理想参数族，本原性由有理gcd与局部化集合决定。59的两个已证仿射元直接给出59Z[1/(2*3*7*19)]。全素数目标应是可逆仿射种子与导群理想本原性的统一证明。

本原性后续也已参数化：若c_i(p)/p对应的整数多项式在Q[X]中互素，则专门化后的共同因子只属于一个固定Bezout整数Delta；Delta局部化后自动得到pR。故根阶段不需逐p验证。剩余核心进一步集中为：构造覆盖有限同余类的真实可逆模板族，并证明其周期/逆在符号参数上成立。

59元坐标复核提供一个更弱的正确资源链：无需先获得标准A_p的逆，已证上三角仿射倍率3/49、-7/243满足乘法关系d_1d_5^2=3^{-9}，校正后直接产生纯三进伸缩。原“标准宏逆”步骤曾混用C基与原基，已在59证明中撤回并替换，完整核验重新通过。
由此可预测的任务是求倍率的有理素数赋值矩阵的整数关系：消去所有非三赋值，留下非零三进赋值，就得到纯三进尺度。还须先能消去仿射平移，并检查这些三幂单位在所需主元模数中的像；仅有赋值关系不自动完成轨道覆盖。

在任何新p上，若种子层一旦启动，可以预测：

- 第一行分桶会产生下三角仿射元；同倍率碰撞产生p倍根。
- 一个非零可逆返回R_p(t)会给上三角仿射元H_t=[[1,1],[0,-1/t]]。
- 若得到U(1)，H_tU(-1)成为纯伸缩，把t分子的素因子同时传给上下根。
- 完整Schreier生成元数量是O(p)，可确定生成；不需群词盲搜。
- 主元同余epsilon=a mod c比“c/p必须是局部单位”更灵活。53、59都只需三进单位完成全部回路。
- 最后的合法轨道和终端不再需要搜索。

不能预测的是某个有限模板语法中第几个宏、哪一个二或三因子词首先产生周期。该编号受可用子问题大小、位置重数碰撞和模板坐标影响，不是群论不变量。

## 4. 非分裂高斯机制的具体候选

有限位置群现已完全识别：[交错群影子](triple_average_nonsplit_alternating_shadow.md)证明(S^{-1}tau)^2是统一三循环，S与tau生成A_p。全部双载体三重划分是循环型1^2 3^r的一个共轭族；其共轭平均在零和空间恰为(p+1)/(3(p-1))I。后者是凸和而非可执行乘积。统一缺口因此属于正Reynolds半群的单位/终端问题，不再是有限置换群大小问题。

删点层进一步识别为原p位置的严格C3 Reynolds算子Q_c=(I+tau_c+tau_c^2)/3，其中tau有两个固定点和(p-2)/3个三循环。任意多层词的迹矩可展开为置换词固定点计数，更高特征系数由Newton恒等式恢复。这把统一种子、仿射根和奇异终端放进同一个Reynolds Hecke代数：分别对应正向单位、二维仿射商和降秩像。详见[非分裂轨道文档第12、13节](triple_average_nonsplit_punctured_orbits.md)。

后续已建立[删点三阶轨道的真实层](triple_average_nonsplit_punctured_orbits.md)：T(x)=-1/(x+1)的特殊轨道{infinity,0,-1}删去infinity后，恰得到两个载体及三重块。将特殊轨道不作平均、其余三元轨道真实平均，可以保持原p位置与总和；无需虚拟位置消元或Schur补。交数矩阵完整预测层转移，但某些转移奇异，尚无全局范数周期。下文Schur补猜想保留为早期候选，不应作为已实现的步骤。

p=1 mod3时，F_p^*中的三阶子群把p-1个非零位置分成三元轨道，加一个载体正好使用p个位置。高斯周期范数给出全局标量循环。

p=2 mod3时，三阶元不在F_p^*中，却在PGL2(F_p)的非分裂环面中。它无固定点地作用于

\[
P^1(F_p),\qquad |P^1(F_p)|=p+1,
\]

并把p+1个点分成(p+1)/3个三元轨道。这是最自然的非分裂对应物，也是为什么直接沿用乘法轨道会多出一个位置。

新的统一候选不是简单增加虚拟位置，而是：在p+1点轨道表示中取一个守恒线性关系，再作Schur补或商表示消去一个点，得到原p位置上的有向三元运输层。需要证明四项：

1. 商表示的每一层能由原p位置真实三平均实现，不能只在形式矩阵上删点。
2. 全部非分裂共轭层的乘积是非零标量，给出正向逆。
3. 某个范数一缺陷产生本原剪切或等价根。
4. 被消去点的关系与模p合法Iwahori格兼容。

47、53、59中“额外一次原子平均后才出现种子”可能正是消去额外射影点的低维影子。现在这只是可检验解释，尚非定理。

## 5. 一个更代数化的统一种子猜想

单一返回之外还有[双迹零返回方案](triple_average_two_trace_zero_returns.md)：保留u、v分别给t=9/(2p+1)、10/(2p+1)，二者在C基的仿射交换子统一为U(10/(2p+1))。固定因子10对应有限模2/5层；模2及p mod5为1、3时影子传递，p mod5为4时两个轨道分别有(0,1)和(1,-3)终端。仍需原位置实现两个返回及S算术根群的有理轨道覆盖，不能只凭有限影子宣布完成。

后续[混合单点条件控制器](triple_average_mixed_singleton_controller.md)在一条明确的充分路线中消除了后一项条件。取B为不超过(p-1)/2且不等于3、5的素数乘积、beta=1/(10B)，R_0与R_beta的仿射交换子给U(1/(B(2p+1)))；两个倍率连同固定因子15局部化后得到完整U(R)，再与标准下仿射元的两个交换子作显式Bezout组合得到L(pR)。已有对角吸收定理随即覆盖全部合法有理方向。因此若采用这个特定控制器，只需证明两个指定缩放返回的原位置实现；根本原性、Schreier参数和终端不再是独立猜想。两个目标的共同严格正三进运输及副本实现已经无条件构造。该条件不是一般种子存在或原可达性的必要条件。

参数周期刚性现在导出唯一符号候选：[统一迹零返回](triple_average_universal_trace_zero_target.md)解得t_p=9/(2p+1)，使(R_p(t_p)A_p)^2=(2p+1)^{-1}I在Q(p)上恒等。沿ord_p(3)的指数等差数列可构造任意小的合法三进尺度lambda，满足lambda=1 mod p且全部类型边际非负、三进。故该返回已在三幂副本空间统一实现。原位置实现会补齐可逆种子层，但还需证明这些相反仿射方向产生本原根理想或直接终端；不能把种子存在等同于完整素数证明。

令T_p为固定1/3重数运输表产生的正向半群，作用于标准核参数格。提出：

> 对所有p=2 mod3、p足够大，T_p含有有限个非奇异元素M_i，使其乘积为非零标量；并且这些元素的第一行方向图含一个仿射倍率碰撞。

第一项给正向逆，第二项给根。该猜想直接涵盖目前固定维数证书，却没有假定周期词长、宏数或具体模板恒定。

可能的证明工具是运输表的有限Hecke代数、非分裂环面的范数，或S单位关系格的正向饱和。仅证明生成代数为End(V)、Zariski稠密或有限模像很大仍然不够，因为这些结论不产生正向标量词。

## 6. 不经过逆元的两条统一备选

[三进运输稳定化](triple_average_triadic_transport_stabilization.md)现证明：精确返回的容量条件对某个三幂副本空间充分。类型边际可取Z[1/3]双随机运输，正则二分图匹配分解把它实现为真实副本三平均。原位置仍缺复制消去；但统一复制路线可缩成只对这种三类型运输证明下降，而非任意复制状态。

所有路线还受[固定词一致性障碍](triple_average_no_oblivious_consensus.md)约束：p>3时不存在一个固定词同时归零全部零和输入。故统一证明只能给出输入相关算法、有限分支下降或先进入低维核；不能把A_p共轭平均的凸标量误当作可执行固定乘积。

若统一周期猜想过强，可以研究：

- 参数化欧几里得下降：每轮按余数选择一个合法宏，使实高度与三进分母的adelic组合严格下降。八元是完整样板；有限模不变和实能量下降单独都不够。
- 终端超平面命中：在运输半群中证明每个合法B_p二维输入最终命中某个三元组和为零的超平面。一次平均产生三个零，统一三零终端立即收尾。

这两条路线的优势是无需整个宏库群化；难点是必须证明有限命中或良序下降，不能以稠密、遍历或数值逼近替代精确等式。

## 7. 后续研究纪律

### 可执行倍率关系定理

设正向可逆群已含F_i=[[1,b_i],[0,d_i]]及U(R)，且所有b_i属于R。
令S为有限个有理数d_i分子分母中出现的素数集合，V_{q,i}=v_q(d_i)。
对任意整数向量e，若所有q!=3满足sum_i V_{q,i}e_i=0，则
product_i d_i^{e_i}=sigma*3^h，其中sigma=+-1，h=sum_i V_{3,i}e_i。
由于Q_i=F_i U(-b_i)=diag(1,d_i)已正向可执行，
product_i Q_i^{e_i}=diag(1,sigma*3^h)也可执行。
若h非零，就取得无限的纯三进伸缩族；若h=0，仅给符号对合，不能误称非平凡伸缩。

求e是有限整数矩阵核问题，可用Smith或Hermite正规形精确求解，无需平均词深搜。
59元两列对应d_1=3/49、d_5=-7/243，非三赋值只有7处(-2,1)。
其核向量e=(1,2)产生h=1-10=-9且sigma=1，解释为什么这些具体分母可以消去。
该例的关系来自指数抵消，而不是猜测某个长群词。
此定理只在F_i的正向逆及U(-b_i)已证时适用；有理倍率的形式关系不能替代物理前提。

不再以“解决下一个素数”作为默认任务。后续计算只服务于以下判别：

1. 检验非分裂PGL2三阶轨道的商表示是否有真实位置实现。
2. 从已有证书反推种子矩阵的参数化重数公式，而非搜索更多编号。
3. 计算运输半群的正向S单位关系格，寻找全正关系的统一证明。
4. 若必须实验，只选能区分上述猜想的少量p；先推导必要筛选、估算规模、分批并行，并冻结命中证书。

59元的意义不是又多一个基例，而是确认：种子一旦存在，根、尖点、同余群和终端全部能由统一公式恢复。未来证明必须集中攻种子存在定理。
