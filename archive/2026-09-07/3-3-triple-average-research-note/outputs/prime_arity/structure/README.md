# 素数证明的结构与简化

当前先读[三个共轭根与浅层提升](transverse_root_lifting_without_long_orbits.md)：奇数n的全部高阶方向／尺度轨道已从九偏移证明中删除，偶数n只保留至多8个二进修正类；统一公式降到p≥83，有限反射证书缩至162组。原180组区间证明保留为前一阶段技术来源。

若先理解构造为何自然出现，读[整格拼接与正运输](integral_gluing_and_positive_transport.md)：典范标记决定同余容器；均匀运输表的有限整数扰动统一产生真实逆。它不宣称已消除剩余180组边界证书。

[p进翻译与典范分支](padic_places_and_canonical_branches.md)区分平均元数p处和危险ℓ处，证明原子秩一退化、端点合法／非法方向的p进稠密性，以及局部循环与加一机的共轭。另核对典范子群、U_p与特征簇文献；尚未得到可直接用于平均的模形式接口。

后续两项更精确的结构：

- [二次群律、形式对数与轨道缺陷](padic_quadratic_group_and_orbit_defect.md)：局部返回是二次代数中的平移，首层缺陷决定所有高层轨道数，统一解释原2／3进条件。已核对180组证书的364个地方。
- [首位乘积与Kneser边界](padic_leading_symbols_and_kneser_boundary.md)：任意词首位由交数乘积给出，2p+1恰是不交图首次连通及两步压缩像从一维变二维的阈值；其下一层首位秩同步从1增至2。带全部算术标记的路径提升仍需证明。
