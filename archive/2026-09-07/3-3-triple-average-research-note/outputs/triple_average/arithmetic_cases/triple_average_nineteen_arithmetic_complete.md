# 十九元完整判据：通用十五元调用与级19同余子群

日期：2026-09-10。

## 1. 结论

**定理。** 非恒等十九元有理状态中心化、清分母并本原化后，有限步三平均可归零，当且仅当 G=1。由[一般三进传播](../history/triple_average_general_n_synthesis.md)第5节，全部 n=19*3^k 中，G为三幂是充要条件。

因此这些维数的判定是输入总位长的多项式时间问题。没有声称原子路径长度有多项式上界。一般n仍未解决；本结果之后又完成了[二十三元](triple_average_twenty_three_arithmetic_complete.md)。当前最小未解维数为20，下一个未解素数维数为29。

证明沿用可复核的结构接口：一般安全核心进入 B19；七个通用宏拥有正向逆实现；六个整数词生成共轭 Gamma_0(19) 的指数20子群；唯一合法尖点有六步终端。

本次七个生成元仅使用3、9、15元子块。十五元调用的普遍合法性由下述显式仿射格恒等式保证，其内部路径由[十五元完整定理](triple_average_fifteen_via_subblocks_complete.md)提供，可能依赖参数。不能把这些宏直接称为固定长度原子词，也不需要依赖十七元定理来证明十九元。

## 3. 正向逆元与三进周期

下列词按时间顺序书写，实际作用均为 lambda I，lambda=-3^(-9)：
\[
PRPR,\qquad Q^6,\qquad TUTU,\qquad ACACAC.
\tag{1}
\]
因此形式逆可替换为以下真实正向宏词：

| 逆元 | 正向词 |
|---|---|
| A^-1 | CACAC |
| C^-1 | ACACA |
| Q^-1 | QQQQQ |
| P^-1 | RPR |
| R^-1 | PRP |
| T^-1 | UTU |
| U^-1 | TUT |

每条词的实际矩阵是 lambda 乘以对应实际矩阵的逆。这是全参数适用的返回模板复合，内部十五元路径仍可依赖输入。

19处恰有 3^9=-1 mod19，因此 lambda=1 mod19。这与[素数稳定子及尺度周期定理](../history/triple_average_prime_congruence_structure.md)一致。该局部周期解释了为什么不能直接照搬十七元中 lambda=-3^(-8) 的关系。

## 4. 精确指数20的充分子群

小写表示上一节已实现的逆元。以下六条词在射影意义下为整数行列式一矩阵：

| 词 | 矩阵 |
|---|---|
| APc | [[-2,1],[-1,0]] |
| pRq | [[-5,-1],[11,2]] |
| tqa | [[-3,-1],[-17,-6]] |
| AQT | [[-6,1],[17,-3]] |
| QQ | [[-7,-1],[43,6]] |
| apQAqP | [[-103,-31],[525,158]] |

令H为其生成的 PSL2(Z) 子群。每个矩阵满足a+b=c+d mod19，所以
\[
H\subseteq H_{19}:=C_0\Gamma_0(19)C_0^{-1},
\qquad C_0=\begin{pmatrix}1&0\\1&1\end{pmatrix}.
\]
H_19是模19直线[1:1]的稳定子，在 PSL2(Z) 中指数20。

对六条整数词作 PSL2(Z)=C2*C3 的精确子群折叠，得到20个完整陪集。独立模19行标签从[1:-1]出发，恰遍历 P1(F19) 的20个点，全部边一致。故
\[
\boxed{H=H_{19}\subseteq\Gamma_{19}^{+}.}
\tag{2}
\]
这证明了一个足够大的正向子群；不把整个三进返回群等同于这个整数子群。

## 5. 一般输入、唯一合法尖点与收尾

对本原 B19 参数，G=gcd(u-v,19)。H有两个 cusp，宽度1的方向不合法，宽度19的方向包含全部合法参数；椭圆点数为0、2，X_0(19) 的属为1。

给定 gcd(u,v)=1、19不整除u-v，取 cu+dv=1，并用
\[
(c,d)\mapsto(c+vk,d-uk)
\]
调整，使 c+d=v-u mod19。由于v-u可逆，k总存在。于是
\[
\begin{pmatrix}v&-u\\c&d\end{pmatrix}\in H_{19}=H,
\qquad
\begin{pmatrix}v&-u\\c&d\end{pmatrix}\binom uv=\binom01.
\]
这个群元素有有限正向宏实现。B19(0,1)=(0^15,1^3,-3) 中取五个零和全部四个非零位置，六次九元网络操作即全局归零。

对一般合法十九元输入，执行补集保留模19见证的非恒等整数三平均，平方和严格下降，故有限终止。由[一般安全核心定理](../history/triple_average_blocker_graph_core.md)，此时至少16个值相同，可写为(u^16,a,b,c)。选c模19不同于u，平均(u,a,b)，即进入合法 B19。这完成全部十九元输入的充分性；必要性仍为已有G不变量。

三进塔传播给出19*3^k全部维数。一般n及多危险素数的进入桥没有因此自动解决。
