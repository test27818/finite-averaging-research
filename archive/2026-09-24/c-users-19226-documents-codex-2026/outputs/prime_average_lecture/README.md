# 素数平均：有限可达性与最优阈值

直接阅读 **prime_average_lecture.pdf**。

这是一份中文 LaTeX 讲义，围绕奇素数 p 的完整可达性判据及最优最终阈值展开：当 n≥2p+1 时，非恒定有理输入可有限步平均至全等，当且仅当本原中心化代表的坐标差最大公因子 G 是 p 的幂；最终阈值为 2p+1。二平均作为独立引用说明其阈值 4。

讲义共69页、18讲，先解释问题和全局路线，再逐层展开整数下降、三块归约、返回矩阵、同余输送和各参数构造。必要的三、五、七平均基例、碰撞分类表、十元二次覆盖表均收入正文，114组上半带根计数作为附录完整保留。前言提供阅读顺序和记号表。

面向具有线性代数、初等数论和基础抽象代数知识的研究生。局部化、本原列、射影返回、主同余子群等均先作说明；Morris、Serre的两个已发表算术群定理明确作为外部定理引用，写出在本问题中的应用。

## 文件

- `prime_average_lecture.pdf`：阅读成品，含可点击目录、书签和交叉引用。

- `chapters/`：18讲及完整计数表的可编辑源码。
- `preamble.tex`、`preface.tex`、`references.tex`：排版、前言与参考文献。
- `compile.py`：独立编译入口；只排版，不运行数学核验。
- `来源说明.md`：章节与既有证明材料的对应。
- `data/`：沿用原项目的必要有限数据及原有有限计算程序，供需要时查阅；阅读和编译均不依赖运行它们。
- `编排说明.md`：编写时确定的结构与范围。

## 修改与编译

在本文件夹运行：

```text
python compile.py
```

需要 XeLaTeX（MiKTeX 或 TeX Live）。字体使用 Windows 的宋体、黑体、楷体、微软雅黑及 Times New Roman；在其他系统上可在 `preamble.tex` 中替换字体名称。也可用编辑器将 XeLaTeX 设为编译引擎，对主文件连续编译三次。

全部源码均在本目录内；不需要原研究项目，也不需要重新运行旧论文的构建程序。编译临时文件由独立编译入口放在临时目录中。
