# 五平均八元到七位置同余块的多项式归约

2026-10-11。本地已给证明，尚未独立重审。对应 FIVE-EIGHT-CLUSTER-REDUCTION。

**定理。** 任意八个有理数的五平均可达性，可以在输入位长多项式时间内，化为多项式多个下列本原整数核心的可达性之“或”：

\[
\boxed{
X=(a^5,a+5s,a+5t,c),\quad
c=-7a-5s-5t,\quad5\nmid a,\quad G(X)=1.
}
\tag{1}
\]

七个位置模 5 同余于 \(a\)，外部位置模 5 同余于 \(3a\)。归约不改变 YES/NO；输出数值的位长不超过原输入位长的常数倍。因此，全五平均八元问题属于 P，**当且仅当**式(1)的受限问题属于 P。

这不是完整的 P 算法。式(1)仍包含此前的指数可达状态族；新增结果把其他剩余类严格消去，使后续研究可以集中在这个与完整问题 P 等价的范围。

## 1 复用与新增范围

已经重读项目接手入口、当前状态、补集核心、固定余量长度界、三值强制段、对偶边界和最新局部精度稿，并运行 context 检索“五平均 八元 p+3 分支”。复用以下已证结论：

- \(n<2p\) 的成功路径必须保持整数；
- 零和本原状态的 \(G=1\) 必要条件；
- \(p=5,n=8\) 任意非恒等整数路径长度为 \(O((1+\log H)^3)\)；
- 三值核心 \((a^5,(a+d)^2,a+v)\) 的 S/T 强制段可多项式处理，直到接受、拒绝或 \(5\mid d\) 的边界。

新增证明是模 5 的三个精确类别及其单向转移、互异类别的确定单项链和多项式出口枚举，最后把全部出口化为式(1)。没有假设三值强制段已经解决其边界。

## 2 三个模 5 类别

核心写为

\[
X=(a^5,a+u_1,a+u_2,a+u_3),\quad
a=-\frac{u_1+u_2+u_3}{8}.
\]

按 \(G=1\) 归一化后，可要求
\(\gcd(u_1,u_2,u_3)=1\) 且 \(8\mid\sum u_i\)。定义物理能量的八倍

\[
K(u)=8\sum_i u_i^2-\left(\sum_i u_i\right)^2.
\tag{2}
\]

它不同于三值强制段文稿中使用的二元范数 \(4d^2+v^2\)。模 5，

\[
K(u)\equiv
(u_1-u_2)^2+(u_2-u_3)^2+(u_3-u_1)^2.
\tag{3}
\]

由此得到三个互斥类别：

| 类别 | 三个差值模 5 的重数 | \(K\bmod5\) |
|---|---|---|
| E | 三者相等 | 0 |
| C | 恰有两者相等 | 2 或 3 |
| D | 三者互不相同 | 1 或 4 |

证明可以同时平移三个余数，再乘一个非零标量，把它们化为 \((0,0,t)\) 或 \((0,1,t)\)。前者 \(K=2t^2\) 为非平方；后者 \(t=2,3,4\)，对应 \(K=1,4,1\)，都是非零平方。全相等则 \(K=0\)。这也证明没有漏掉其他情况。

**E 类直接不可解。** 三个相等余数不能都是 0，否则违反本原条件。因此它们为某个非零 \(t\)；任何一个或两个例外的差值和都不被 5 整除，三个差值的和也非零模 5，既没有非恒等真子集操作，也不是公共值为零的终端。全例外非终端操作落入不可解两常值块。

## 3 单项操作保持类别 双项操作只进入 C 或失败

选择单个差值 \(u_i=5q\) 的操作为

\[
u'_i=-q,\qquad u'_j=u_j-q\ (j\ne i).
\tag{4}
\]

它保持本原：输出公因子必整除 \(q\) 及全部旧坐标，所以只能是 1。并且

\[
\boxed{K(u')=K(u)-160q^2.}
\tag{5}
\]

因此非恒等单项操作保持 \(K\bmod5\)，也就保持 C/D 类别。式(5)还给出严格能量下降。

选择两个例外后，这两个坐标都变成同一个差值。约去共同内容后，它们仍然相等。因此合法非零输出只可能是 C 或 E，永远不是 D。E 已经证明失败。由此：

**C 类对所有可能成功的后继封闭；D 类一旦选双项，就永久离开 D。**

这里“合法归一化”还包含既有的 \(8\mid\sum u'_i\) 检查；如果约去差值 gcd 后不满足它，输出违反本原全状态的 \(G=1\) 必要条件，应拒绝。

## 4 D 类只须枚举一条确定链的出口

D 类三个余数互异，至多一个差值被 5 整除，因此至多有一个非恒等单项操作。三个不同余数中，和为零的二元子集也至多一个。

从 D 类输入出发，沿其唯一单项操作前进；在每个节点保存合法双项出口。如果没有单项操作，停止该链。任何成功词只有两种形式：

1. 沿这条链直接到达公共值为零的终端；
2. 在链上某个节点第一次使用双项操作，从此进入 C 类。

第二类出口实际上具有两个**完全相等**的差值，即三个实际值的物理核心。因为单项链保持整数且无恒等步，其长度由已有路径界限制为 \(O(B^3)\)，其中 \(B=1+\log H\)。每个节点的候选出口为常数个，工作整数位长为 \(O(B)\)。所以可以用多项式时间列出全部必要出口，无须在 D 类递归分支。

还有一个可用的提前拒绝：若 D 类余数为 \((0,t,-t)\)，双项选择的是后两项。设其差值和为 \(5q\)。当 \(5\nmid q\) 时，输出三个差值全同余于 \(-q\)，约分内容又不能含 5，故输出属于 E，立即失败。因此这种出口只有在选中差值和被 25 整除时才值得保留。检查仍需同时满足 \(G\) 条件；被 25 整除不保证可解。

## 5 C 类再归约到七位置同余块

把 C 类余数排列为 \((t,t,s)\)，其中 \(t\ne s\)。终端先单独检查。其余只有以下情况：

- **\(t=0\)**：已经有两个差值被 5 整除，正是式(1)。
- **\(s=0\)**：只有孤立例外的单项操作可能非恒等；所有双项和均非零模 5。沿这个唯一操作继续，直到离开该情况，或者失败、终止。长度仍受 \(O(B^3)\) 界限制。
- **\(s,t\ne0\)**：没有单项操作。只有在 \(s=-t\) 时，才有两个可能的双项选择；否则没有成功后继。每个双项输出都有两个实际相等的差值。

对于最后一项的每个合法输出，调用已有的三值 S/T 强制段算法。它只可能接受、拒绝，或者到达重复差值 \(d\) 满足 \(5\mid d\) 的边界。后一情形的第三差值为 5 进单位，正是式(1)。

所以一个 C 类输入可以多项式归约为**至多两个**式(1)的输入。过程中不会重新生成 C 类的一般分支树：一次双项后就是三值强制段，而该算法在第一个 \(5\mid d\) 边界停止，不继续枚举边界。

另外，在保持例外坐标标签时，一段纯单项操作不会改变“哪两个坐标模5相等”。选择孤立坐标时，另外两项减去同一个数；选择同余对中的一项时，这两项必须都为0模5，输出仍然同余。故这种配对只可能在双项操作时改变。这一性质不消除七位置块内部的二选一，但可以用于下一步描述其操作词。

结合第4节，任意核心可以多项式归约为多项式多个式(1)输入的“或”。如果初态还没有五重值，只须枚举第一步的 \(\binom85=56\) 个选择；中心化、清分母和本原化均保持多项式位长。归约遂覆盖全部八个有理输入。

反方向显然成立，因为式(1)只是原问题的子集。这证明开头的 P 等价，而不是把研究目标替换成一个不充分的特例。

## 6 实现与独立核验

实现为 five_eight_residue_reduction.py：

- reduce_core / reduce_input 输出 C 类出口；
- reduce_core_to_clusters / reduce_input_to_clusters 输出式(1)的出口；
- immediate 为 true 或 false 时已经得到完整判定；为 None 时返回待判定实例的“或”，不能解释成判否；
- decide_input 调用原完整求解器处理剩余实例，因此仍为完整有限算法，但没有宣称该调用具有多项式界。资源超限继续抛异常，不冒充 NO。

核验器 verify_five_eight_residue_reduction.py 实际通过：

- 全部 125 个模 5 余数组合，E/C/D 分别为 5/60/60 个；
- 2549 个核心及其两层归约、180 个完整原输入和对应有理仿射变换，共 360 次完整输入核验，与 8932 态的独立整数 DAG 一致；
- 1500 个精确能量恒等式检查及4个反向构造的确定链；最长链2000步，输入差值4644位，正确完整处理。

记录为 five_eight_residue_reduction_verification.json。有限计算核对代码与样例；多项式上界和全范围等价由第2至5节承担。

## 7 剩下的精确问题

现在只需对式(1)给出关于位长的多项式判定，便可推出全部五平均八元属于 P。这里 \(s,t\) 不要求相等，也不要求只有一位共同 5 进精度。

仍不能直接枚举七位置块内的所有词。既有 \((1^5,1+5^{2k},1-5^{2k},-7)\) 就属于式(1)，已有 \(2^k\) 个不同合法 G=1 状态的证明。对相等例外的高精度模合成也不能替代精确到零。

下一步须解决七位置块内部的多分支、第一次改变外部位置后的返回，以及这些阶段的隐式合并。本稿没有证明这个剩余步骤属于 P，也没有证明 NP 困难。
